On-Source Repositories & Internal Cache

High-speed tier-1 structure sources directly indexed for instant zero-latency retrieval, including Materials Project (MP-API) and local high-precision CIF stores.

🏛️

Materials Project Core (MP-API)

Primary DFT database containing over 150,000 verified inorganic structures. Queried via formula and chemical system criteria with energy-above-hull sorting to prioritize thermodynamic ground states.

Latency: < 250msREST v2
💾

Local High-Precision Cache

Pre-relaxed float64 CIF structures stored locally in indexed binary format. Eliminates network roundtrips for frequent industrial compounds (Fe₂O₃, TiO₂, Si, NaCl, etc.).

Latency: < 5msIn-Memory
🔍

Ground-State Selector

When multiple matches exist in on-source stores, structures with energy above hull = 0.000 eV/atom are automatically designated as the default parent lattice.

Criteria: E_hullAutomated
