TECHNICAL ARCHITECTURE ROADMAP

Implementation Plan & System Specifications

Complete end-to-end execution flow from login authentication and element balance to MACE-MP-0 float64 relaxation, CrystaLLM generative fallbacks, and scientific .dat export.

01

Authentication & Environment Gate

Secure login splash view validating user credentials before mounting the crystallographic workspace. Detects local GPU/CPU hardware and verifies MACE-MP-0 model checkpoint readiness.

Status: COMPLETEDSecurity: JWT + Session Token
02

Interactive Element Input & Stoichiometry Balancer

Real-time compositional breakdown into atomic weight fractions, element cards, valence charge checks, and invalid input clearing. Allows instant reset and formula undo.

Status: COMPLETEDEngine: pymatgen Composition
03

Formula Review & Search Directing Stage

Redirects user to an explicit review modal: "I am searching for this formula [Fe₂O₃]". Offers options to Confirm & Run Pipeline, Change formula, or Go Back to adjust dopant fractions.

Status: COMPLETEDInteraction: Multi-action Routing
04

High-Performance Pipeline Execution

Animated execution stages displaying live progress: Classification → Database Lookup (MP / COD / AFLOW) → Doping Transformation → CrystaLLM Generative Fallback → MACE-MP-0 float64 Relaxation.

Status: COMPLETEDPrecision: float64 Double Precision
05

Polymorphism Screening & Symmetry Matrix

Evaluates polymorph stability ranking (e.g. Anatase vs Rutile). Computes full 3x3 metric tensor, Cartesian rotation matrices, translation vectors, and Wyckoff site table.

Status: COMPLETEDSpacegroup: SpacegroupAnalyzer
06

MESP Calculation & Scientific .dat Export

Verifies electrostatic charge balance, net deviation, bond valence sums, and generates auto-executable Python validation scripts. Emits benchmark tables to scientific .dat files.

Status: COMPLETEDOutputs: .dat Formats
